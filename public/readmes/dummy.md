### System Architecture

The system utilizes a modern frontend stack paired with a lightweight backend to maximize throughput while minimizing latency. 

Here is a quick overview of the stack:

1. **Frontend**: React + Vite + Tailwind CSS
2. **Animation**: Framer Motion
3. **Database**: PostgreSQL (Dummy)
4. **Deployment**: Vercel
